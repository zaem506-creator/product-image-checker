# فحص صور المنتج + الإيجنت

- `public/index.html`: أداة فحص الصور نفسها، ومضاف لها زر **🤖 افحص بالإيجنت**.
- `agent/`: الإيجنت. سيرفر صغير يشتغل على جهازك، يرسل كل صورة لـ Claude ومعها قواعد الفريق وأمثلة من قراراتكم، ويرجّع القرار (مطابق / مرفوض / يحتاج مراجعة) مع السبب بنفس نصوص الفريق.

## الطريقة الأسهل: بدون تثبيت أي برنامج

1. نزّل ملف **`public/index.html`** وافتحه بدبل كلك. يفتح في المتصفح (Chrome أو Edge).
2. في خانة **"الإيجنت — مفتاح Claude"** حط مفتاحك واضغط **حفظ المفتاح**. تاخذ المفتاح من **console.anthropic.com**: من **Settings → Billing** اشحن رصيد، ومن **Settings → API Keys** اضغط **Create Key**.
3. حط الروابط أو ارفع الصور، اضغط **افحص**، وبعدها **🤖 افحص بالإيجنت**.
4. صحّح أغلاطه بـ **✕ غلط**. كل تصحيح يصير مثال يتعلم منه على طول، ونسبة دقته في الصور اللي صحّحتها تطلع لك في نفس الخانة.

ملاحظات:
- المفتاح ينحفظ في متصفحك بس، ما ينحفظ داخل الملف. لا تختار "تذكّر المفتاح" في جهاز مشترك.
- الأمثلة اللي تعلمها محفوظة في هذا المتصفح. عشان تنقلها لزميل أو لجهاز ثاني، استخدم **تصدير الأمثلة** و**استيراد أمثلة**.
- الصور اللي يفحصها الإيجنت تنرسل لـ Claude، أي لشركة Anthropic. تأكد إن هذا مسموح في سياسة شركتك.
- لو طلع لك "ما قدرت أوصل لـ Claude"، معناه شبكة الشركة حاجبة `api.anthropic.com`.

### مجاناً بـ GitHub Models

في خانة الإيجنت اختار **GitHub Models — مجاني بحد يومي**، وحط توكن GitHub بدل مفتاح Claude:
1. ادخل github.com، واضغط صورتك ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. سمّه، وحدد مدة انتهاء، ومن **Permissions** أضف **Models** واختار **Read-only**. اضغط **Generate token** وانسخه (يبدأ بـ `github_pat_`).
3. حطه في الأداة واضغط **حفظ المفتاح**.

حدود المجاني: تقريباً 50 صورة في اليوم، حسب المصادر. وأنا ما قدرت أتأكد من الرقم من GitHub مباشرة. والموديل (GPT-4.1) أقل دقة من Claude في التفاصيل الدقيقة. الأمثلة والتصحيحات نفسها تشتغل مع الخدمتين.

## الطريقة الثانية: مع سيرفر على جهازك (تحتاج Node.js)

بهالطريقة المفتاح يبقى على السيرفر، وتقدر تقيس الدقة على ملف قراراته معروفة (`npm run eval`).

## التشغيل أول مرة (ويندوز)

1. نزّل وثبّت **Node.js** (نسخة 22.9 أو أحدث) من https://nodejs.org
2. خذ مفتاح API من **console.anthropic.com**:
   - **Settings → Billing**: أضف بطاقة واشحن رصيد.
   - **Settings → API Keys**: اضغط **Create Key** وانسخ المفتاح.
3. دبل كلك على **`Start-Agent.bat`**. أول مرة بيفتح لك ملف `agent\.env` في Notepad. حط المفتاح بعد `ANTHROPIC_API_KEY=` واحفظ الملف.
4. دبل كلك على `Start-Agent.bat` مرة ثانية. الأداة تنفتح في المتصفح على http://localhost:8787

> المفتاح يبقى في ملف `agent\.env` على جهازك بس. لا ترسله لأحد ولا ترفعه على GitHub (الملف مستثنى من git).

على ماك أو لينكس: `cd agent && npm install && cp .env.example .env`، حط المفتاح في `.env`، وبعدها `npm start`.

## الاستخدام

1. حط الروابط أو ارفع الصور واضغط **افحص**، نفس قبل.
2. اضغط **🤖 افحص بالإيجنت**. كل صورة يطلع تحتها قرار الإيجنت والسبب، ولو قرار الأداة كان غيره ينكتب "الأداة كانت: …".
3. ملف الـ Excel والملاحظة يمشون على قرار الإيجنت. عمود **Checked by** يقول مين حكم على كل صورة: الإيجنت أو الأداة.
4. تحت كل قرار فيه زرين **✓ صح** و **✕ غلط**. لو ضغطت "غلط"، اختار القرار الصحيح والسبب، واكتب ليش لو تبي، واضغط حفظ.

## تعليم الإيجنت

كل تصحيح ينحفظ في `agent/data/feedback.jsonl`. عشان يتعلم منها:

```
cd agent
npm run learn
```

الأمر ياخذ كل صورة غلط فيها الإيجنت ويضيفها مع قراركم الصحيح إلى `agent/examples/`. بعدها سكّر السيرفر وشغّله مرة ثانية، والإيجنت يشوف هالأمثلة قبل كل صورة يفحصها.

نصائح:
- أهم الأمثلة هي الحالات الحدّية، مثل ظل خفيف مقبول وظل قوي مرفوض، أو يد مطبوعة على العلبة ويد حقيقية ماسكة المنتج.
- كتابة "ليش" مع التصحيح تفرق كثير.
- لا تكثّر الأمثلة. 20 إلى 40 مثال واضح أحسن من 200، لأن كل مثال يزيد وقت وتكلفة كل فحص. تقدر تعدّل `agent/examples/examples.json` بيدك وتشيل الأمثلة المكررة.

## قياس الدقة (هدف الـ95%)

لا تعتمد على الإحساس. قِس:

```
cd agent
npm run eval                      # يقيس على كل التصحيحات المحفوظة
npm run eval -- labels.csv        # أو على ملف قراراته معروفة
```

`labels.csv`: نزّل ملف Excel من الأداة، وخل المراجع يصحّح عمودي **Status** (Approved / Rejected) و **Reason**، واحفظه **CSV UTF-8**.

النتيجة تطلع:
- **Correct approve/reject decision**: نسبة القرارات الصحيحة. هذا رقم الـ95%.
- كم صورة راحت "يحتاج مراجعة" بدل ما يحكم عليها.
- كم مرة **قبل صورة المفروض تنرفض**، وكم مرة **رفض صورة سليمة**.
- لكل سبب: كم مرة صاب، وكم مرة أضافه غلط، وكم مرة فوّته. من هنا تعرف أي قاعدة تحتاج أمثلة أكثر.
- `agent/data/eval-results.csv`: كل صورة مع قرار الفريق وقرار الإيجنت جنب بعض.

الصور اللي صارت أمثلة تنستثنى من القياس تلقائياً، لأن الإيجنت يعرف جوابها.

الطريقة: صحّح ← `npm run learn` ← `npm run eval` ← كرر لين توصل للنسبة اللي تبيها. وقِس على صور جديدة ما صارت أمثلة.

## إعدادات (في `agent/.env`)

| الإعداد | الافتراضي | وش يسوي |
|---|---|---|
| `AGENT_MODEL` | `claude-opus-5-5` | الموديل اللي يحكم |
| `AGENT_EFFORT` | `high` | قد إيش يفكر قبل ما يحكم (`low` / `medium` / `high` / `xhigh` / `max`). أعلى = أدق غالباً بس أبطأ وأغلى |
| `AGENT_VOTES` | `1` | كم مرة يفحص نفس الصورة. لو `3` واختلفت الإجابات، الصورة تروح "يحتاج مراجعة" بدل التخمين. يرفع الدقة على اللي يحكم عليه، بس التكلفة تصير 3 أضعاف |
| `AGENT_PARALLEL` | `4` | كم صورة يفحص في نفس الوقت |
